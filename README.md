# Petal Key

Offline Android keyboard. This preview includes optional on-device English voice typing. Live speech/provider accuracy and ARM32 qualification remain pending. See source notices for upstream licensing.

Download the APK and full corresponding source ZIP from [Releases](https://github.com/ClownChowder/petal-key/releases). Upstream copyright notices, model/audio credits and licenses are retained in the source and app assets. This repository indexes personal preview releases; the automatic GitHub source archives are not the app source. Use the explicitly attached `petal-key-source.zip`.
